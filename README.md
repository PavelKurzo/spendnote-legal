# SpendNote legal

Public Privacy Policy and Terms of Use for the **SpendNote** iOS app.

SpendNote helps people log everyday spending, keep a personal savings note, and split shared costs in Spaces. It is not a bank, and it does not convert currencies.

## Documents

Once GitHub Pages is on, these are the URLs to use in App Store Connect and in the app:

- [Privacy Policy](https://pavelkurzo.github.io/spendnote-legal/privacy.html)
- [Terms of Use](https://pavelkurzo.github.io/spendnote-legal/terms.html)

You can also open them in this repo: [`privacy.html`](privacy.html) and [`terms.html`](terms.html).

## GitHub Pages

Turn Pages on once: repo **Settings → Pages → Deploy from a branch → `main` / `/ (root)`**.

After that, the home page is [https://pavelkurzo.github.io/spendnote-legal/](https://pavelkurzo.github.io/spendnote-legal/).
